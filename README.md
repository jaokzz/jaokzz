# FitSaaS - Gestão de Treinos

Plataforma SaaS para gerenciamento de treinos em academias, com foco em experiência do aluno, organização semanal e acompanhamento de progresso.

## ✨ Estrutura do projeto

- `backend/`: API REST em Node.js + TypeScript + Fastify
- `frontend/`: Interface Next.js (App Router) + TailwindCSS + shadcn/ui

## ✅ Funcionalidades

- Autenticação segura (email/senha, Google, Apple)
- Perfil completo do aluno com anamnese de saúde
- Treinos organizados por semana e com registro de carga
- Dashboard com consistência, sequência e taxa de conclusão
- Progresso semanal, mensal e trimestral

## 🚀 Como rodar

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Acesse `http://localhost:3000` para visualizar a interface.
